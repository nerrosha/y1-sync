Y1 Sync for Windows (portable)

Run "Y1 Sync.exe". Keep the other files in this folder next to it:
  y1sync.exe       the engine
  ffmpeg.exe       reads music files (LGPL, see FFMPEG-LICENSE.txt)
  ffprobe.exe

First, turn on USB storage on the player itself; it does not appear until you do.
Windows may say it does not know the publisher: this app is not code-signed.
Choose "More info" then "Run anyway".

Not tested on a real Windows PC or a real Y1. Please report anything odd:
https://github.com/nerrosha/y1-sync/issues
